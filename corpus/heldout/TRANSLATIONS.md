# Held-out translations (hand-made, validated)

Generated by `geosolver-bench/heldout/scripts/problems.py` (numeric figure builder + validator). Every translated problem is a fully pinned figure (`name@x_y`), built from the official statement's configuration; the engine re-checks every premise on it (`ddar --corpus-check`). For each: the official statement, the AG1 text, the independent numeric checks of the OFFICIAL (undirected) statement on that figure, and a perturbation under which the goal must fail.

Flags: `pinned-implicit` = a hypothesis defines a point implicitly, so the figure is pinned where it holds and the hypothesis is an overdetermined premise (AG2's own format does this for every point); `answer-supplied` = 'find' problem stated as 'prove the value'; `helper-points` = extra points that only encode a hypothesis or a tangency; `contaminated` = the problem was used during GeoSolver development.
