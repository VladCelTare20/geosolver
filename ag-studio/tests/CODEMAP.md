# ag-studio/tests — integration tests of the shipped binary and assets

Up: [../../CODEMAP.md](../../CODEMAP.md)

## Files
- `worker_binary.rs` — the real `agstudio` binary: the `__solve-worker` subcommand and a `serve` whose solves go through it.
- `mobile_css.rs` — phone invariants read from `assets/` source: hover rules behind `@media (hover: hover)`, 16 px touch fields, safe-area gutters, `--vh-dyn`, 48 px touch targets, narrow-screen wrapping, the Back-button layers, iOS field attributes. Part of `cargo test`.
- `webkit/iphone-layout.mjs` — the same behaviour in a browser: Playwright WebKit with the iPhone SE / 15 / 15 Pro Max presets, portrait and landscape, against a running server. Not run by `cargo test`.
- `webkit/iphone-e2e.mjs` — the whole product flow on iPhone SE / 15 / 15 Pro Max, portrait and landscape, light and dark: password page → app → example solve → step tap → pinch and pan → PDF and PNG export → AI explanation → Describe → Photo → Romanian; with `ACCOUNTS_BASE`, also landing → register → history drawer. Not run by `cargo test`.
- `webkit/android-layout.mjs` — Chromium (Android user agent, mobile viewport, touch) and Firefox (viewport + touch, Firefox-for-Android user agent) at Pixel 7, Pixel 5, Galaxy S9+, Galaxy S23, Moto G4, Galaxy Fold cover (280) and unfolded (717×512, 673×841), 320×568 and page-zoom equivalents of a 360 px phone (288, 240, 215, 180), portrait and landscape, light/EN and dark/RO: gate, app, Syntax, Examples, result, Export menu, full-screen figure, and with `ACCOUNTS_BASE` landing, sign in, register. Fails on sideways scroll, anything past the screen edge, clipped text, overlapping header controls and touch targets under 48 px that crowd a neighbour (44 px allowed in the header below 360 px; not checked at page-zoom widths, where a CSS px is physically larger). `FONT_SCALES=125,150,200` also runs with a larger root font size. Not run by `cargo test`.
- `webkit/android-e2e.mjs` — the product flow on Android sizes: Chrome installability (`Page.getInstallabilityErrors`) and the manifest icons; gate (password-manager field, Enter submits), `theme-color`, example solve, step tap, a real two-finger pinch through CDP `Input.dispatchTouchEvent` (the page itself must not zoom), pan, full screen closed by Back with the scroll position kept, PDF/PNG downloaded then shared from the toast (share stub), Copy proof read back from the clipboard, AI explanation, Describe, Photo (JPEG via `PHOTO`), Romanian; with `ACCOUNTS_BASE` register, history drawer closed by Back. Firefox runs at two sizes. Same server setup as `iphone-e2e.mjs`.
- `webkit/fake-claude.sh` — stands in for the `claude` CLI (`AGSTUDIO_CLAUDE_BIN`) in browser tests: answers `--version` and `auth status`, returns a fixed `.geo` block for translations and a fixed EN/RO explanation for `/api/humanize`, and copies the uploaded `problem.*` to `$FAKE_CLAUDE_LOG`.

## Notes
- `webkit/iphone-layout.mjs` — run against a guest-mode server: `PLAYWRIGHT_MODULE=<playwright>/index.mjs PLAYWRIGHT_BROWSERS_PATH=<browsers> BASE=http://127.0.0.1:<port> BASIC_PASSWORD=<pw> node ag-studio/tests/webkit/iphone-layout.mjs` (`SHOTS=<dir>` saves screenshots). It checks the page never scrolls sideways (also with Syntax open at 320 px), the editor is 16 px, nothing sits under simulated 59 px landscape notch strips (it overrides `--sai-l/r`), a step tap shows the figure peek, and the double-tap rules. Emulation has no real safe areas, keyboard or focus zoom; those need a device. With the form gate (`AGSTUDIO_GATE=form`, the default) it types `BASIC_PASSWORD` into `/gate` first.
- `webkit/iphone-e2e.mjs` — start two servers with the same password and `AGSTUDIO_CLAUDE_BIN=ag-studio/tests/webkit/fake-claude.sh`, `CLAUDE_CODE_OAUTH_TOKEN=dummy` (counts as signed in), one with `AGSTUDIO_GUEST_MODE=1` and one with `0`, and the rate limits off (`AGSTUDIO_RATE_PER_MIN=0 AGSTUDIO_TRANSLATE_PER_MIN=0 AGSTUDIO_AUTH_PER_MIN=0`), then `PLAYWRIGHT_MODULE=… PLAYWRIGHT_BROWSERS_PATH=… GUEST_BASE=http://127.0.0.1:<p1> ACCOUNTS_BASE=http://127.0.0.1:<p2> BASIC_PASSWORD=<pw> SHOTS=<dir> node ag-studio/tests/webkit/iphone-e2e.mjs`. The photo is `docs/example-report.png` unless `PHOTO` is set. `navigator.share` is replaced by a recorder on portrait runs (WebKit on Linux has none), so the share path is checked for a fresh user activation and the file's type and magic bytes, never the real share sheet; landscape runs take the download path. Screenshots use `animations: 'disabled'`: three pages run at once and WebKit throttles the toast fade-in and `IntersectionObserver` of a page that is not frontmost, which otherwise shows up as an invisible toast or a figure thumbnail that has not hidden yet.
