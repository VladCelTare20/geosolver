# ag-studio/tests — integration tests of the shipped binary and assets

Up: [../../CODEMAP.md](../../CODEMAP.md)

## Files
- `worker_binary.rs` — the real `agstudio` binary: the `__solve-worker` subcommand and a `serve` whose solves go through it.
- `mobile_css.rs` — iPhone invariants read from `assets/` source: hover rules behind `@media (hover: hover)`, 16 px touch fields, safe-area gutters, `--vh-dyn`, 44 px touch targets, iOS field attributes. Part of `cargo test`.
- `webkit/iphone-layout.mjs` — the same behaviour in a browser: Playwright WebKit with the iPhone SE / 15 / 15 Pro Max presets, portrait and landscape, against a running server. Not run by `cargo test`.
- `webkit/iphone-e2e.mjs` — the whole product flow on iPhone SE / 15 / 15 Pro Max, portrait and landscape, light and dark: password page → app → example solve → step tap → pinch and pan → PDF and PNG export → AI explanation → Describe → Photo → Romanian; with `ACCOUNTS_BASE`, also landing → register → history drawer. Not run by `cargo test`.
- `compat.rs` — the browser baseline read from `assets/` source: CSS values newer than the baseline (`color-mix`, `dvh`/`svh`, container units, …) only after a plain fallback of the same property or inside `@supports`; `:has()` and other late selectors never in a selector list; no CSS nesting, `@layer`, `@property`, …; every `@container` has an `@supports not (container-type: inline-size)` fallback; no JS API newer than the baseline (`findLast`, `structuredClone`, `AbortSignal.timeout`, `requestIdleCallback`, regex lookbehind, …); `navigator.share` and `.inert` only with their fallbacks; inline scripts ES5; every scripted page has the guard, both notes and `GS.booted`. Part of `cargo test`.
- `compat-inventory.mjs` — every CSS property/value/selector/at-rule/unit, HTML element/attribute and JS API in `assets/` against `@mdn/browser-compat-data` for the baseline, `BELOW` rows first. Needs `npm i --prefix <dir> @mdn/browser-compat-data acorn acorn-walk postcss`, then `COMPAT_DEPS=<dir>/node_modules node ag-studio/tests/compat-inventory.mjs`. Not run by `cargo test` (network).
- `webkit/compat-robustness.mjs` — Chromium, Firefox and WebKit against running servers: the old-browser guard (EN/RO), a failed `app.js`, JavaScript off, storage and cookies refused, cookies blocked (Firefox), offline mid-solve and back, a silent connection (fake clock), Slow 3G + 4× CPU, no native `inert`, a client clock 3 h fast, 40 solves (heap, DOM nodes, listeners), a server restart mid-session (with `AGSTUDIO_BIN`), and a solve in each engine. `ONLY=guard,offline,…` picks checks. Not run by `cargo test`.
- `desktop_css.rs` — tablet/desktop invariants read from `assets/` source: the print stylesheet (light tokens, no controls, figure unsplit), the figure wheel never trapping page scroll (pinned check, Ctrl/⌘ pinch, `deltaMode`, Safari gestures), paste/drop anywhere, the ≥ 1800 px and 1024–1199 px column rules, contrast and forced-colour state. Part of `cargo test`.
- `webkit/desktop-e2e.mjs` — the whole product flow in Chromium, Firefox and WebKit on laptop/desktop and iPad profiles (1366×768; 1920×1080 at DPR 1.25 dark Romanian; iPad Air portrait touch; iPad Pro and iPad mini landscape with a trackpad): password page by keyboard → Examples menu by keyboard + Escape → Ctrl+Enter solve → arrow keys through steps → figure + / 0 / F / Escape → wheel (zooms the side figure, scrolls past an in-page one, pans a zoomed one), Ctrl+wheel, Safari gesture pinch, pen drag → PDF/PNG/SVG downloads → Copy proof (clipboard checked in Chromium) → AI explanation → print media → Describe → paste and drop of an image → Photo → compile error → busy 503 → language switch; with `ACCOUNTS_BASE` (an accounts-mode server, no password), landing → register by keyboard → history rail at 1440 → reopen by Enter → drawer at 1024. Not run by `cargo test`.
- `webkit/fake-claude.sh` — stands in for the `claude` CLI (`AGSTUDIO_CLAUDE_BIN`) in browser tests: answers `--version` and `auth status`, returns a fixed `.geo` block for translations and a fixed EN/RO explanation for `/api/humanize`, and copies the uploaded `problem.*` to `$FAKE_CLAUDE_LOG`.

## Notes
- `webkit/iphone-layout.mjs` — run against a guest-mode server: `PLAYWRIGHT_MODULE=<playwright>/index.mjs PLAYWRIGHT_BROWSERS_PATH=<browsers> BASE=http://127.0.0.1:<port> BASIC_PASSWORD=<pw> node ag-studio/tests/webkit/iphone-layout.mjs` (`SHOTS=<dir>` saves screenshots). It checks the page never scrolls sideways (also with Syntax open at 320 px), the editor is 16 px, nothing sits under simulated 59 px landscape notch strips (it overrides `--sai-l/r`), a step tap shows the figure peek, and the double-tap rules. Emulation has no real safe areas, keyboard or focus zoom; those need a device. With the form gate (`AGSTUDIO_GATE=form`, the default) it types `BASIC_PASSWORD` into `/gate` first.
- `webkit/iphone-e2e.mjs` — start two servers with the same password and `AGSTUDIO_CLAUDE_BIN=ag-studio/tests/webkit/fake-claude.sh`, `CLAUDE_CODE_OAUTH_TOKEN=dummy` (counts as signed in), one with `AGSTUDIO_GUEST_MODE=1` and one with `0`, and the rate limits off (`AGSTUDIO_RATE_PER_MIN=0 AGSTUDIO_TRANSLATE_PER_MIN=0 AGSTUDIO_AUTH_PER_MIN=0`), then `PLAYWRIGHT_MODULE=… PLAYWRIGHT_BROWSERS_PATH=… GUEST_BASE=http://127.0.0.1:<p1> ACCOUNTS_BASE=http://127.0.0.1:<p2> BASIC_PASSWORD=<pw> SHOTS=<dir> node ag-studio/tests/webkit/iphone-e2e.mjs`. The photo is `docs/example-report.png` unless `PHOTO` is set. `navigator.share` is replaced by a recorder on portrait runs (WebKit on Linux has none), so the share path is checked for a fresh user activation and the file's type and magic bytes, never the real share sheet; landscape runs take the download path. Screenshots use `animations: 'disabled'`: three pages run at once and WebKit throttles the toast fade-in and `IntersectionObserver` of a page that is not frontmost, which otherwise shows up as an invisible toast or a figure thumbnail that has not hidden yet.
- `webkit/compat-robustness.mjs` — `GUEST_BASE` (guest mode) and `ACCOUNTS_BASE` (guest mode off) servers as for `iphone-e2e.mjs`; `AGSTUDIO_BIN=<agstudio>` lets it start, kill and restart its own server on `RESTART_PORT` (default 19249) for the restart check. Playwright's engines are current releases, so it checks behaviour (fallback paths are forced by deleting the API in an init script), not old engines.
- `webkit/desktop-e2e.mjs` — the guest server as in production (`AGSTUDIO_BASIC_AUTH=:<pw>`, `AGSTUDIO_GUEST_MODE=1`, the fake `claude`, rate limits off) and, for `ACCOUNTS_BASE`, a second one with no password and `AGSTUDIO_GUEST_MODE=0`; then `PLAYWRIGHT_MODULE=… PLAYWRIGHT_BROWSERS_PATH=… GUEST_BASE=… ACCOUNTS_BASE=… BASIC_PASSWORD=<pw> SHOTS=<dir> node ag-studio/tests/webkit/desktop-e2e.mjs` (`ENGINES=chromium,firefox,webkit`, `PROFILE=<name>` narrows it). Synthetic input stands in for what Playwright cannot produce: pen strokes and Safari `gesture*` pinches are dispatched events, a pasted image is a `ClipboardEvent` with a `DataTransfer` (Firefox cannot build one: reported as SKIP), and mobile WebKit has no wheel (SKIP). Real trackpad momentum, Apple Pencil hover, Windows high-contrast themes and the printer dialog need hardware.
