Angles written ∠ are read from the figure.
∡(a, b) is the angle through which line a must be turned counter-clockwise to become parallel to b, taken modulo 180°; ∡XYZ means ∡(YX, YZ). These angles do not depend on how the figure is drawn.
Directed angles are needed only in steps 5 and 7, where the figure-angle form would depend on the configuration.
Let Ω be the circumcircle of triangle ABC, with centre O; N, S, E, P lie on Ω.
Let ω₁ be the circle centred at O₁ through B, D, L, P.

Plan: it suffices to show that A, I, X are collinear.

1. We show that NB = NC:
    ∠NBC = ∠NAC    [inscribed angles in Ω]
         = ∠BAN    [AI bisects ∠BAC]
         = ∠BCN    [inscribed angles in Ω]
Hence NB = NC. (1)
2. OB = OC and, by (1), NB = NC, so ON is the perpendicular bisector of BC; hence ON ⟂ BC. (2)
3. We show that T, E, S, O are concyclic:
    ∠BTO = 90° − ∠SBE    [OT ⟂ BE]
         = 90° − ∠SNE    [inscribed angles in Ω]
         = ∠OSE          [NS is a diameter]
         = ∠SEO          [OS = OE: triangle OSE is isosceles]
So T, E, S, O are concyclic. (3)
4. We show that T, P, X, O are concyclic:
    ∠OTX = ∠EBS + 90°            [OT ⟂ BE]
         = ∠EBP + ∠PBS + 90°     [angle addition]
         = ∠EBP + ∠PNO + 90°     [inscribed angles in Ω]
         = ∠EBC − ∠NPB + 180°    [ON ⟂ BC, by (2)]
         = ∠BLD − ∠NPB + 180°    [DL ∥ BC]
         = ∠NPD                  [inscribed angles in ω₁]
         = ∠XPD + ∠NPX           [angle addition]
         = ∠PBX + ∠NPX           [PX is tangent to ω₁ (tangent–chord angle)]
         = ∠PNO + ∠NPX           [inscribed angles in Ω]
         = ∠OPN + ∠NPX           [ON = OP: triangle ONP is isosceles]
         = ∠OPX                  [angle addition]
So T, P, X, O are concyclic. (4)
5. We show that T, P, E, D are concyclic:
    ∡ETD = ∡EON                        [T, E, S, O concyclic, by (3)]
         = ∡(OE, BC) + 90°             [ON ⟂ BC, by (2)]
         = ∡(OE, DL) + 90°             [DL ∥ BC]
         = ∡OEB + ∡BLD + 90°           [angle addition]
         = ∡OEB + ∡BPD + 90°           [inscribed angles in ω₁]
         = ∡OEA + ∡BPD + ∡AEB + 90°    [angle addition]
         = ∡OEA + ∡BPD + ∡APB + 90°    [inscribed angles in Ω]
         = ∡OEA + ∡APD + 90°           [angle addition]
         = ∡EPD                        [OA = OE: triangle OAE is isosceles; central angle ∠AOE = 2∠APE]
So T, P, E, D are concyclic. (5)
6. We show that XA = XP:
    ∠AOX = ∠AOP − ∠XOP    [angle addition]
         = ∠AOP − ∠PTB    [T, P, X, O concyclic, by (4)]
         = ∠AOP − ∠AEP    [T, P, E, D concyclic, by (5)]
         = ∠AEP           [central angle ∠AOP = 2∠AEP]
         = ∠BTP           [T, P, E, D concyclic, by (5)]
         = ∠XOP           [T, P, X, O concyclic, by (4)]
OA = OP, so △OAX ≅ △OPX (SAS). Hence XA = XP. (6)
7. We show that A, I, X are collinear:
    ∡IAX = ∡SAX + 90°           [NS is a diameter]
         = ∡PAX + ∡SAP + 90°    [angle addition]
         = ∡PAX + ∡XBP + 90°    [inscribed angles in Ω]
         = ∡PAX + ∡DPX + 90°    [PX is tangent to ω₁ (tangent–chord angle)]
         = ∡XPA + ∡DPX + 90°    [XA = XP: triangle XAP is isosceles, by (6)]
         = ∡DPA + 90°           [angle addition]
         = ∡BPA + ∡DPB + 90°    [angle addition]
         = ∡BEA + ∡DPB + 90°    [inscribed angles in Ω]
         = ∡BEA + ∡DLB + 90°    [inscribed angles in ω₁]
         = ∡LDA + 90°           [angle addition]
         = ∡(BC, AD) + 90°      [DL ∥ BC]
         = 0°                   [AD ⟂ BC]
So A, I, X are collinear. (7)
8. A, I, X collinear, by (7) and AI bisects ∠BAC, so AX bisects ∠BAC, as required. ∎
